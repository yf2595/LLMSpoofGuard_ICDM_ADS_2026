# Evaluation outputs

All files in this directory (except this README) are **generated by running the
evaluation scripts**. They are not hand-edited or pre-filled.

| Script | Outputs |
|--------|---------|
| `python scripts/run_benchmark.py` | `results.json`, `results.csv`, `plots/` |
| `python -m evaluation.run_evaluation --no-skip-llm` | same + LLM baseline metrics |
| `python scripts/run_prompt_ablation.py` | `prompt_ablation.json`, `.csv`, `plots/prompt_ablation_table.png`, `prompt_ablation_raw/*.jsonl` |
| `python scripts/run_llm_comparison.py` | `llm_comparison.json`, `.csv`, `plots/llm_comparison_table.png`, `llm_comparison_raw/*.jsonl` |

Each JSON file includes a `dataset` block with trajectory counts, split seed, and
label policy so reviewers can verify the run configuration.

Per-trajectory raw LLM responses are written to `*_raw/` subdirectories for audit.
